### Аккаунт и вход (M16, M21)
- [ ] Регистрация и вход по e-mail + пароль, подтверждение e-mail
- [ ] Sign in with Apple
- [ ] Вход через Google
- [ ] Восстановление доступа
- [ ] Face ID / Touch ID на iPhone
- [ ] Удаление аккаунта из приложения (обязательно для App Store)
- [ ] Онбординг: базовая валюта, вопросы о персоне, первый счёт и первая транзакция меньше чем за 2 минуты
- [ ] Онбординг: 3–5 повторяющихся операций (аренда, зарплата, перевод семье) и экран с обещанием о приватности

### Ядро учёта (M01, M02, M03)
- [ ] Личные счета всех типов, в том числе иностранные, наличные и кошельки

- [ ] Отображение сумм в базовой и в исходной валюте
- [ ] Переводы между своими счетами, в том числе в разных валютах, с учётом комиссии
- [ ] Доходы и расходы: категории, теги, сплиты, вложения
- [ ] Повторяющиеся операции
- [ ] Быстрый ручной ввод: шаблоны, последние категории и счета
- [ ] Общий список «To review» для всех автоматически созданных транзакций
- [ ] Поиск дубликатов между чеками, импортом и ручным вводом
- [ ] Корзина «Recently deleted» на 30 дней

### Данные и поддержка (M23, M24)
- [ ] Полный экспорт данных

- [ ] Status page

### Платформы
- [ ] Веб-версия
- [ ] iPhone-приложение прошло ревью App Store (подписки, Sign in with Apple, удаление аккаунта, privacy label)

### 🔒 Security gate — MVP
- [ ] Данные защищены при хранении и передаче, опубликовано обещание «кто может видеть мои данные»
- [ ] 2FA доступна всем пользователям, с кодами восстановления
- [ ] Face ID / Touch ID / PIN на открытие iPhone-приложения
- [ ] Privacy mode: скрытие сумм на экране
- [ ] Оповещение о входе с нового устройства или из новой страны, кнопка «This wasn't me»
- [ ] Список активных сессий, выход с одного или со всех устройств
- [ ] Защита от перебора паролей, блокировка при подозрительной активности, проверка паролей по базам утечек
- [ ] Повторная аутентификация для чувствительных действий (смена e-mail/пароля/2FA, экспорт, удаление)
- [ ] AI-ассистент видит только данные текущего пользователя
- [ ] Защита от инструкций, спрятанных в чеках и импортируемых файлах
- [ ] Проверка загружаемых файлов и лимиты (выписки до 20 MB и 5 000 строк, чеки до 10 MB)
- [ ] Исходные выписки по умолчанию удаляются сразу после импорта
- [ ] Полный экспорт данных пользователя самостоятельно, без поддержки
- [ ] Удаление аккаунта и данных: отключение сразу, восстановление в течение 7 дней, очистка за 30 дней, бэкапы за 90 дней
- [ ] Данные пользователей не используются для обучения AI без согласия, есть экран согласий
- [ ] Поддержка видит данные только по разрешению пользователя, максимум на 72 часа, с записью в журнал
- [ ] Публичная privacy policy простым языком
- [ ] Процедура уведомления пользователей об инцидентах в течение 72 часов, отрепетирована
- [ ] Независимый security review / pentest перед публичным запуском, все high-severity находки исправлены

### Критерии выхода MVP
- [ ] Weekly Tracked Users из beachhead-сегмента: 500+ (минимум 200)
- [ ] Activation: 40%+ новых пользователей внесли 10+ транзакций за первую неделю
- [ ] Retention D30 ≥ 25% (минимум 20%)
- [ ] Free → Paid к 60-му дню ≥ 3%, 100+ платящих пользователей Personal
- [ ] Медианное время ручного ввода транзакции ≤ 6 секунд, не растёт
- [ ] Доля транзакций, введённых не вручную, ≥ 35%
- [ ] Ноль нарушений границ AI-ассистента
- [ ] Рейтинг в App Store ≥ 4.5

## Phase 3 — v2+

Приоритет задач уточняется в конце v1. Подробно: [`roadmap/03-v2-plus.md`](../../docs/product/roadmap/03-v2-plus.md).

- [ ] Учёт дивидендов, в том числе мультивалютных

- [ ] Без рекомендаций по покупке и продаже

### Переход от конкурентов (M23) — приоритет 2
- [ ] Импорт из YNAB, Monarch, Mint-экспортов и таблиц

### Бизнес (M08) — приоритет 3
- [ ] Роль accountant с доступом только на чтение и только к бизнес-профилям

### Каналы (M13) — приоритет 4
- [ ] Slack для Business
- [ ] SMS / iMessage: оценить и запустить
- [ ] Групповой режим для семьи: только ввод, без балансов

### Расширение — приоритеты 5–12
- [ ] Расширенная аналитика и отчёты: итоги года, произвольные периоды, сравнения (M10)
- [ ] Подростки в семье и карманные деньги (M09)
- [ ] Общий журнал долга с контрагентом (M05)
- [ ] Сценарии рефинансирования и досрочных платежей (M04)
- [ ] Автоматическое распознавание популярных форматов выписок (M18)
- [ ] Интерфейс на испанском, затем другие языки по спросу
- [ ] Android: оценить необходимость (порог: ≥ 30% новых регистраций просят Android, Q21)
- [ ] Пакет Family + Business (если решён Q6) (M15)

### Масштабирование
- [ ] Продукт стабильно держит 10 000 одновременных пользователей при всех целевых NFR
- [ ] Доступность 99.95% за квартал
- [ ] План роста в 10 раз без изменений для пользователя

### 🔒 Security gate — v2+
- [ ] SOC 2 Type I
- [ ] SOC 2 Type II
- [ ] Регулярные pentest: минимум раз в год и после крупных запусков
- [ ] Ежегодный пересмотр privacy policy и согласий
- [ ] Роль accountant только на чтение и только к бизнес-профилям
- [ ] Требования безопасности для каждого нового канала (Slack, SMS/iMessage) и для Android

### Критерии выхода v2+
- [ ] Инвестиции: ≥ 25% платящих P1 ведут хотя бы один инвестиционный счёт, ноль нарушений границ советов
- [ ] Импорт из других приложений: ≥ 15% новых регистраций переносят историю
- [ ] Business: в среднем ≥ 2 seats на аккаунт, есть отчёт SOC 2 Type II
- [ ] Платный отток P1 ≤ 3% в месяц

## Сквозное (на всех фазах)

- [ ] App Store: требования к подпискам и Sign in with Apple соблюдены в каждом релизе
- [ ] Финансовые и AI-дисклеймеры актуальны в каждом релизе
- [ ] Trust-чек-лист релиза из [PRD §9](../../docs/product/prd/09-compliance-and-trust.md#trust-checklist-per-release) пройден
- [ ] Метрики North Star, activation, retention и конверсии отслеживаются с первого дня
- [ ] Время ввода по каждому способу измеряется, регрессии блокируют релиз
- [ ] Guardrails не ухудшаются: отписка от уведомлений, рейтинг App Store, возвраты, жалобы на приватность
- [ ] Обратная связь от пользователей собирается и разбирается регулярно
- [ ] Маркетинговое позиционирование «no bank sync + privacy-first» совпадает с реальными функциями
- [ ] Без банковской синхронизации, перемещения денег и персональных финансовых советов (решение не пересматривается без фаундера)
